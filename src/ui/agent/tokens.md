# Tokens

Every value in Otherstates UI. Reference them as `t['--os-…']` after `import { tokens as t } from '@/ui/tokens.stylex'`.
Dark values come from theme.ts; a blank dark cell means the light value applies. Generated by src/ui/agent/build-docs.mjs.
